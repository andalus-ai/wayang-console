# Wayang Console web

This directory is reserved for the standalone Console frontend, not the Wayang Studio workflow editor.

The first UI milestone is fleet overview, environments, runtime inventory, enrollment, deployments, topology, observability, and audit.

Frontend technology and shared design-system extraction should be aligned with the existing Wayang Flutter Studio before choosing a framework. Console consumes only the versioned management API and read-only workflow visualization contracts. Do not copy Studio's workflow canvas into this application.
